📝 Создание списка

Списки в Python создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные.

garage = ['Lada Granta', 'Niva Travel', 'Lada Vesta'] empty_list = list()

🔢 Индексация

Каждый элемент имеет свой индекс, начиная с 0. Индексы могут быть отрицательными: -1 — это последний элемент, -2 — предпоследний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0]) # Lada Granta print(car_models[-1]) # Lada Vesta # Изменение элемента car_models[1] = 'Niva Travel'

✂️ Срезы списка

Срез — это подпоследовательность. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[:3]) # с 0 по 2 индекс print(cars[1:3]) # с 1 по 2 индекс

➕ Добавление элементов

Для добавления используются методы:

  • append(x) — в конец списка.
  • insert(i, x) — на конкретную позицию.

➕ Добавление: метод append()

garage = ['Lada Granta', 'Niva Travel'] garage.append('Aurus Senat') print(garage) # ['Lada Granta', 'Niva Travel', 'Aurus Senat']

📍 Добавление: метод insert()

garage = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] garage.insert(1, 'УАЗ Патриот') print(garage) # ['Lada Granta', 'УАЗ Патриот', 'Niva Travel', 'Aurus Senat']

🗑️ Удаление элементов

  • remove(x) — удаляет по значению.
  • pop(i) — удаляет по индексу.
  • del — удаляет по индексу или срез.
  • clear() — полностью очищает список.

🗑️ Удаление: метод remove()

variables = [10, 'Python', 3.14, 'Python'] variables.remove('Python') # [10, 3.14, 'Python']

🗑️ Удаление: метод pop()

car_models = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] car_models.pop(1) # Удалит 'Niva Travel' print(car_models) # ['Lada Granta', 'Aurus Senat']

🗑️ Удаление: оператор del

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] del cars[1] # Удалит 'Niva' print(cars) # ['Lada', 'Vesta', 'УАЗ']

🗑️ Удаление: метод clear()

cart = ['Смартфон', 'Чехол', 'Книга'] cart.clear() print(cart) # []

🔗 Метод extend()

cars_russia = ['Lada', 'Niva'] cars_china = ['Changan', 'Exeed'] cars_russia.extend(cars_china) # ['Lada', 'Niva', 'Changan', 'Exeed']

🔠 Сортировка и реверс

numbers = [10, 2, 11, 9, 3] numbers.sort() # [2, 3, 9, 10, 11] numbers.reverse() # [11, 10, 9, 3, 2]

🕵️ Проверка вхождения (in)

fruits = ['яблоко', 'банан', 'апельсин'] if 'банан' in fruits: print("Банан есть в списке!")

📊 Полезные функции

numbers = [10, 2, 11, 9] print(len(numbers)) # 4 print(sum(numbers)) # 32 print(max(numbers)) # 11 print(min(numbers)) # 2

✂️➡️📝 Методы строк: split() и join()

words = "Python is awesome".split() # ['Python', 'is', 'awesome'] text = "-".join(['a', 'b', 'c']) # 'a-b-c'

📑 Копирование списков

list1 = [1, 2, 3] list2 = list1.copy() list1.clear() # list1 = [], list2 = [1, 2, 3]

🛒 Практика: Управление готовой корзиной

Представим, что у нас есть готовый список покупок. Мы можем удалить конкретный товар по его названию (через remove) или полностью очистить корзину (через clear).

shopping_list = ['Хлеб', 'Молоко', 'Сыр', 'Яблоки'] # 1. Удаление товара на выбор (по названию) product_to_remove = 'Молоко' if product_to_remove in shopping_list: shopping_list.remove(product_to_remove) print(f"Товар '{product_to_remove}' удален из корзины.") print("Текущая корзина:", shopping_list) # 2. Завершение покупки или полная очистка action = 'clear' # Представим, что пользователь выбрал очистку if action == 'clear': shopping_list.clear() print("\nКорзина полностью очищена.") print("Итоговый список:", shopping_list)
Вывод: Товар 'Молоко' удален из корзины.
Текущая корзина: ['Хлеб', 'Сыр', 'Яблоки']

Корзина полностью очищена.
Итоговый список: []

⌨️ Практика: Добавление нескольких товаров

Давайте напишем мини-программу, которая просит ввести товар и цену, а затем спрашивает: «Добавить еще?». Если пользователь отвечает «да», цикл повторяется. Если «нет» — выводится итоговый чек.

shopping_list = [] price_list = [] while True: # Запрашиваем данные у пользователя product = input('Введите название товара: ') price = float(input('Введите стоимость товара: ')) # Добавляем в списки shopping_list.append(product) price_list.append(price) # Спрашиваем, продолжать ли answer = input('Добавить еще товар? (да/нет): ').lower() if answer != 'да': break # Выходим из цикла, если ответ не "да" # Красивый вывод print("\n--- ВАШ ЧЕК ---") for i in range(len(shopping_list)): print(f"{shopping_list[i]} — {price_list[i]:g} руб.") # Считаем общую сумму total = sum(price_list) print(f"Итого: {total:g} руб.") print("---------------")

Введите название товара: Сыр
Введите стоимость товара: 150
Добавить еще товар? (да/нет): нет
