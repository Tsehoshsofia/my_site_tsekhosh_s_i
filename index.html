📝 Создание списка

Списки в Python создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные.

garage = ['Lada Granta', 'Niva Travel', 'Lada Vesta'] empty_list = list()

🔢 Индексация

Каждый элемент имеет свой индекс, начиная с 0. Индексы могут быть отрицательными: -1 — это последний элемент, -2 — предпоследний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0]) # Lada Granta print(car_models[-1]) # Lada Vesta # Изменение элемента car_models[1] = 'Niva Travel'

✂️ Срезы списка

Срез — это подпоследовательность. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[:3]) # с 0 по 2 индекс print(cars[1:3]) # с 1 по 2 индекс

➕ Добавление элементов

Для добавления используются методы:

  • append(x) — в конец списка.
  • insert(i, x) — на конкретную позицию.

➕ Добавление: метод append()

garage = ['Lada Granta', 'Niva Travel'] garage.append('Aurus Senat') print(garage) # ['Lada Granta', 'Niva Travel', 'Aurus Senat']

📍 Добавление: метод insert()

garage = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] garage.insert(1, 'УАЗ Патриот') print(garage) # ['Lada Granta', 'УАЗ Патриот', 'Niva Travel', 'Aurus Senat']

🗑️ Удаление элементов

  • remove(x) — удаляет по значению.
  • pop(i) — удаляет по индексу.
  • del — удаляет по индексу или срез.
  • clear() — полностью очищает список.

🗑️ Удаление: метод remove()

variables = [10, 'Python', 3.14, 'Python'] variables.remove('Python') # [10, 3.14, 'Python']

🗑️ Удаление: метод pop()

car_models = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] car_models.pop(1) # Удалит 'Niva Travel' print(car_models) # ['Lada Granta', 'Aurus Senat']

🗑️ Удаление: оператор del

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] del cars[1] # Удалит 'Niva' print(cars) # ['Lada', 'Vesta', 'УАЗ']

🗑️ Удаление: метод clear()

cart = ['Смартфон', 'Чехол', 'Книга'] cart.clear() print(cart) # []

⌨️ Задача 1: Добавление товаров в конец

Давайте напишем мини-программу, которая просит ввести товар и цену, а затем спрашивает: «Добавить еще?». Если пользователь отвечает «да», цикл повторяется. Если «нет» — выводится итоговый чек.

Обратите внимание на форматирование :g при выводе цены. Оно убирает лишние нули у целых чисел (например, 50.0 превращает в 50), но сохраняет копейки (например, 99.50 останется 99.5).

shopping_list = [] price_list = [] while True: # Запрашиваем данные у пользователя product = input('Введите название товара: ') price = float(input('Введите стоимость товара: ')) # Добавляем в конец списков (append) shopping_list.append(product) price_list.append(price) # Спрашиваем, продолжать ли answer = input('Добавить еще товар? (да/нет): ').lower() if answer != 'да': break # Красивый вывод (с :g) print("\n--- ВАШ ЧЕК ---") for i in range(len(shopping_list)): print(f"{shopping_list[i]} — {price_list[i]:g} руб.") # Считаем общую сумму total = sum(price_list) print(f"Итого: {total:g} руб.") print("---------------")
Пример работы программы: Введите название товара: Молоко
Введите стоимость товара: 99
Добавить еще товар? (да/нет): да

Введите название товара: Хлеб
Введите стоимость товара: 65
Добавить еще товар? (да/нет): нет

--- ВАШ ЧЕК ---
Молоко — 99 руб.
Хлеб — 65 руб.
Итого: 164 руб.
---------------

📍 Задача 2: Вставка товара по индексу

А что, если нам нужно вставить срочный товар не в конец, а на определенное место?

Пользователи привыкли считать с единицы. Чтобы программа поняла, что «место 1» — это нулевой индекс в Python, мы вычтем 1 из введенного числа (index - 1). А чтобы программа не сломалась от слишком большого числа, применим min().

shopping_list = ['Хлеб', 'Молоко'] price_list = [65, 99] print("Текущий список:") for i in range(len(shopping_list)): print(f"{i + 1}. {shopping_list[i]}") # Спрашиваем срочный товар urgent_product = input('\nВведите срочный товар: ') urgent_price = float(input('Введите его стоимость: ')) # Спрашиваем место (начиная с 1) user_place = int(input(f'На какое место поставить (от 1 до {len(shopping_list) + 1})? ')) # Переводим в индекс Python (вычитаем 1) и защищаем от выхода за границы index = min(user_place - 1, len(shopping_list)) # Вставляем по индексу (insert) shopping_list.insert(index, urgent_product) price_list.insert(index, urgent_price) # Проверяем результат (с :g) print("\n--- ОБНОВЛЕННЫЙ СПИСОК ---") for i in range(len(shopping_list)): print(f"{shopping_list[i]} — {price_list[i]:g} руб.")
Пример работы программы: Текущий список:
1. Хлеб
2. Молоко

Введите срочный товар: Сметана
Введите его стоимость: 85
На какое место поставить (от 1 до 3)? 1

--- ОБНОВЛЕННЫЙ СПИСОК ---

Молоко — 99 руб.

🗑️ Задача 3: Удаление товара по названию

Представим, что пользователь передумал покупать конкретный товар. Мы спрашиваем его название и удаляем первый найденный элемент через remove().

Важно: перед удалением нужно проверить, есть ли товар в списке (через in), чтобы программа не выдала ошибку.

cart = ['Молоко', 'Хлеб', 'Сметана', 'Сыр'] print("Текущая корзина:", cart) product_to_remove = input('Какой товар удалить? ') if product_to_remove in cart: cart.remove(product_to_remove) print(f"\nТовар '{product_to_remove}' удален.") print("Новая корзина:", cart) else: print("\nТакого товара нет в корзине.")
Пример работы программы: Текущая корзина: ['Молоко', 'Хлеб', 'Сметана', 'Сыр']
Какой товар удалить? Сметана

Товар 'Сметана' удален.
Новая корзина: ['Молоко', 'Хлеб', 'Сыр']

🗑️ Задача 4: Удаление по номеру (индексу)

Иногда проще удалить товар не по названию, а по его номеру в списке. Пользователь вводит номер (с 1), а мы переводим его в индекс (вычитая 1) и удаляем через del или pop.

Разница: del просто удаляет, а pop() удаляет и возвращает значение (его можно сохранить в переменную).

cart = ['Молоко', 'Хлеб', 'Сметана', 'Сыр'] print("Ваша корзина:") for i in range(len(cart)): print(f"{i + 1}. {cart[i]}") # Пользователь вводит номер (от 1 до 4) user_num = int(input('\nКакой по счету товар удалить? ')) # Переводим в индекс Python if 1 <= user_num <= len(cart): index_to_remove = user_num - 1 # Способ 1: через del (просто удаляет) del cart[index_to_remove] # Способ 2: через pop (удаляет и возвращает значение) # removed_item = cart.pop(index_to_remove) print("\nТовар удален.") print("Новая корзина:", cart) else: print("\nОшибка: такого номера нет.")

1. Молоко
2. Хлеб
3. Сметана
4. Сыр

Какой по счету товар удалить? 2

Товар удален.

🛍️ Практика: Выбор товара из готового каталога

Теперь представим, что у нас есть готовый каталог товаров и цен. Пользователь выбирает нужные ему товары по названию, а программа формирует чек.

catalog_products = ['Хлеб', 'Молоко', 'Сметана', 'Сыр'] catalog_prices = [65, 99, 85, 150] cart_products = [] cart_prices = [] while True: print("\nДоступные товары:", catalog_products) choice = input('Что купить? (или "стоп" для завершения): ') if choice.lower() == 'стоп': break if choice in catalog_products: # Находим индекс товара в каталоге idx = catalog_products.index(choice) # Добавляем в корзину cart_products.append(catalog_products[idx]) cart_prices.append(catalog_prices[idx]) print(f"Добавлено: {choice} за {catalog_prices[idx]} руб.") else: print("Такого товара нет.") # Оформление покупки print("\n--- ОФОРМЛЕНИЕ ПОКУПКИ ---") if len(cart_products) > 0: for i in range(len(cart_products)): print(f"{cart_products[i]} — {cart_prices[i]:g} руб.") total = sum(cart_prices) print(f"Итого: {total:g} руб.") else: print("Корзина пуста.")

✂️ Практика: Показать только часть каталога

Иногда нужно вывести не весь список, а только его часть (например, первые три товара). В этом нам помогут срезы.

catalog_products = ['Хлеб', 'Молоко', 'Сметана', 'Сыр', 'Масло'] catalog_prices = [65, 99, 85, 150, 120] # Выводим первые 3 товара (срезы с 0 по 2 индекс) print("Топ-3 товара:") for i in range(3): print(f"{catalog_products[i]} — {catalog_prices[i]:g} руб.") # Или используем срез списка напрямую print("\nСрез цен (первые 3):", catalog_prices[:3])
