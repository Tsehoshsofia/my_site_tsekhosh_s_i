📝 Создание списка

Списки создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные.

garage = ['Lada Granta', 'Niva Travel']

🔢 Индексация

Индексы начинаются с 0. Отрицательные индексы идут с конца: -1 - последний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0])

Список: ['Lada', 'KIA', 'Vesta', 'УАЗ']

✂️ Срезы списка

Срез: [начало:конец:шаг]. Конечный индекс не включается.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[1:3])

Список: ['Lada', 'Niva', 'Vesta', 'УАЗ']

➕ Добавление: append()

Метод append(x) добавляет элемент строго в конец списка.

garage = ['Lada', 'Niva'] garage.append('Aurus')

Список: ['Lada', 'Niva']

📍 Добавление: insert()

Метод insert(index, value) вставляет элемент на конкретную позицию.

garage = ['Lada', 'Niva', 'Aurus'] garage.insert(1, 'УАЗ')

Список: ['Lada', 'Niva', 'Aurus']

🗑️ Удаление: remove()

Метод remove(x) удаляет первый элемент по значению.

cart = ['Молоко', 'Хлеб', 'Сметана'] cart.remove('Хлеб')

Список: ['Молоко', 'Хлеб', 'Сметана']

🗑️ Удаление: pop() и del

Удаляют по индексу. del просто удаляет, а pop() удаляет и возвращает значение.

cart = ['Молоко', 'Хлеб', 'Сметана'] del cart[1] # или cart.pop(1)

Список: ['Молоко', 'Хлеб', 'Сметана']

🗑️ Удаление: clear()

Метод clear() полностью очищает список.

cart = ['Молоко', 'Хлеб', 'Сметана'] cart.clear()

Список: ['Молоко', 'Хлеб', 'Сметана']

📍 Задача 2: Вставка товара по индексу

А что, если нам нужно вставить срочный товар не в конец, а на определенное место?

Пользователи привыкли считать с единицы. Чтобы программа поняла, что "место 1" - это нулевой индекс в Python, мы вычтем 1 из введенного числа (index - 1). А чтобы программа не сломалась от слишком большого числа, применим min().

shopping_list = ['Хлеб', 'Молоко'] price_list = [65, 99] print("Текущий список:") for i in range(len(shopping_list)): print(f"{i + 1}. {shopping_list[i]}") product = input('\nВведите срочный товар: ') price = float(input('Введите его стоимость: ')) user_place = int(input(f'На какое место поставить (от 1 до {len(shopping_list) + 1})? ')) index = min(user_place - 1, len(shopping_list)) shopping_list.insert(index, product) price_list.insert(index, price) print("\n--- ОБНОВЛЕННЫЙ СПИСОК ---") for i in range(len(shopping_list)): print(f"{shopping_list[i]} - {price_list[i]:g} руб.")

Текущий список: Хлеб (65), Молоко (99)

🗑️ Задача 4: Удаление по номеру (индексу)

Иногда проще удалить товар не по названию, а по его номеру в списке. Пользователь вводит номер (с 1), а мы переводим его в индекс (вычитая 1) и удаляем через del или pop.

shopping_list = ['Молоко', 'Хлеб', 'Сметана', 'Сыр'] print("Ваша корзина:") for i in range(len(shopping_list)): print(f"{i + 1}. {shopping_list[i]}") number = int(input('\nКакой по счету товар удалить? ')) if 1 <= number <= len(shopping_list): index = number - 1 del shopping_list[index] # или: removed_item = shopping_list.pop(index) print("\nТовар удален.") print("Новая корзина:", shopping_list) else: print("\nОшибка: такого номера нет.")

Корзина: 1. Молоко, 2. Хлеб, 3. Сметана, 4. Сыр
