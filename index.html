Введение в списки Python

1. Создание списка

Списки в Python создаются с помощью квадратных скобок [] или функции list(). Каждый элемент списка может быть любым типом данных.

my_list = [] # пустой список
my_list = list() # пустой список

numbers_list = [40, 20, 90, 11, 5]
car_models_list = ['Lada Granta', 'Lada Vesta', 'Niva Travel']
mixed_list = [3.14, 10, 'Hello world!', False, 'Python is the best']

2. Индексация

Списки индексируются, начиная с 0. Вы можете обращаться к элементам по индексам, чтобы получать, изменять или заменять их.

car_models = ['Lada Granta', 'Niva Travel', 'Lada Vesta', 'УАЗ Патриот', 'Aurus Senat']
print(car_models[0])
print(car_models[1])
Lada Granta
Niva Travel

Индексирование работает и в обратную сторону. Индекс -1 дает доступ к последнему элементу, -2 к предпоследнему и т.д.

print(car_models[-1])
print(car_models[-2])
Aurus Senat
УАЗ Патриот

3. Срезы списка

Срезом называется подпоследовательность. Синтаксис среза: переменная[начальный_индекс:конечный_индекс_минус_1:шаг].

car_models = ['Lada Granta', 'Niva Travel', 'Lada Vesta', 'УАЗ Патриот']
print(car_models[:3])  # с 0 по 2 индекс
print(car_models[1:3]) # с 1 по 2 индекс
print(car_models[1:])  # с 1 до конца
['Lada Granta', 'Niva Travel', 'Lada Vesta']
['Niva Travel', 'Lada Vesta']
['Niva Travel', 'Lada Vesta', 'УАЗ Патриот']

4. Добавление элементов

Метод append() добавляет элемент в конец списка. Метод insert() добавляет элемент на заданную позицию.

my_list = [1, 2, 3]
my_list.append(4)
print(my_list)

my_list.insert(1, 9) # вставить 9 на индекс 1
print(my_list)
[1, 2, 3, 4]
[1, 9, 2, 3, 4]

5. Удаление элементов

Метод remove() удаляет первый элемент по указанному значению. Метод pop() удаляет элемент по индексу (или последний, если индекс не указан). Оператор del также удаляет по индексу.

variables_list = [10, True, 'Python', 3.14, 'Python']
variables_list.remove('Python') 
print(variables_list)

car_models = ['Lada Granta', 'Lada Vesta', 'Niva Travel']
car_models.pop()
print(car_models)

del variables_list[0]
print(variables_list)
[10, True, 3.14, 'Python']
['Lada Granta', 'Lada Vesta']
[True, 3.14, 'Python']

6. Полезные функции и методы

В Python есть встроенные функции для работы со списками, такие как len(), sum(), min(), max(), а также методы sort(), reverse() и count().

numbers = [10, 2, 11, 9, 3, 24, 57, 78]
print(len(numbers))     # Длина списка
print(sum(numbers))     # Сумма элементов
print(max(numbers))     # Максимум
print(min(numbers))     # Минимум

numbers.sort()          # Сортировка
print(numbers)

numbers.reverse()       # Разворот списка
print(numbers.count(11))# Количество вхождений

7. Оператор in и цикл for

Оператор in проверяет наличие элемента в списке (возвращает True или False). Цикл for позволяет перебирать элементы списка.

fruits = ['яблоко', 'апельсин', 'груша', 'ананас']

if 'яблоко' in fruits:
    print("Яблоко есть в списке!")

for fruit in fruits:
    print(fruit)
Яблоко есть в списке!
