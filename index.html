Создание списка

Списки в Python создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные.

garage = ['Lada Granta', 'Niva Travel', 'Lada Vesta'] empty_list = list()

Индексация

Каждый элемент имеет свой индекс, начиная с 0. Индексы могут быть отрицательными: -1 — это последний элемент, -2 — предпоследний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0]) # Lada Granta print(car_models[-1]) # Lada Vesta # Изменение элемента car_models[1] = 'Niva Travel'

Срезы списка

Срез — это подпоследовательность. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается. Шаг может быть отрицательным для обратного порядка.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[:3]) # с 0 по 2 индекс print(cars[1:3]) # с 1 по 2 индекс print(cars[4:2:-1]) # в обратном порядке

Добавление элементов

Чтобы расширить список, в Python есть два основных метода:

  • append(x) — добавляет элемент в конец списка.
  • insert(i, x) — вставляет элемент на конкретную позицию (по индексу), сдвигая остальные.

Добавление: метод append()

Метод append() добавляет новый элемент строго в конец списка.

garage = ['Lada Granta', 'Niva Travel'] garage.append('Aurus Senat') print(garage) # Результат: ['Lada Granta', 'Niva Travel', 'Aurus Senat']

Добавление: метод insert()

Метод insert(index, value) вставляет элемент на конкретную позицию. Все элементы, которые были после указанного индекса, сдвигаются вправо.

garage = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] garage.insert(1, 'УАЗ Патриот') print(garage) # Результат: ['Lada Granta', 'УАЗ Патриот', 'Niva Travel', 'Aurus Senat']

Удаление элементов

В Python есть несколько способов удалить элемент из списка, в зависимости от задачи:

  • remove(x) — удаляет по значению.
  • pop(i) — удаляет по индексу (или последний, если индекс не указан).
  • del — оператор для удаления по индексу или среза.
  • clear() — полностью очищает список.

Удаление: метод remove()

Метод remove(x) ищет элемент по значению и удаляет первое совпадение.

variables = [10, 'Python', 3.14, 'Python'] variables.remove('Python') # Удалит первый 'Python' print(variables) # Результат: [10, 3.14, 'Python']

Удаление: метод pop()

Метод pop(index) удаляет элемент по индексу и возвращает его. Если индекс не указан, удаляется последний элемент.

car_models = ['Lada Granta', 'Niva Travel', 'Aurus Senat'] car_models.pop(1) # Удалит 'Niva Travel' print(car_models) # Результат: ['Lada Granta', 'Aurus Senat']

Удаление: оператор del

Оператор del удаляет элемент по индексу или целый срез. В отличие от pop(), он ничего не возвращает.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] del cars[1] # Удалит 'Niva' print(cars) # Результат: ['Lada', 'Vesta', 'УАЗ']

Удаление: метод clear()

Метод clear() удаляет все элементы из списка, оставляя его пустым.

cart = ['Смартфон', 'Чехол', 'Книга'] cart.clear() print(cart) # Результат: []

Метод extend()

Объединяет два списка: берет второй список и дописывает его элементы в конец первого.

cars_russia = ['Lada', 'Niva'] cars_china = ['Changan', 'Exeed'] cars_russia.extend(cars_china) # ['Lada', 'Niva', 'Changan', 'Exeed']

Сортировка и реверс

sort() сортирует по возрастанию. reverse() переворачивает список.

numbers = [10, 2, 11, 9, 3] numbers.sort() # [2, 3, 9, 10, 11] numbers.reverse() # [11, 10, 9, 3, 2]

Проверка вхождения (in)

Оператор in возвращает True, если элемент есть в списке, и False, если нет.

fruits = ['яблоко', 'банан', 'апельсин'] if 'банан' in fruits: print("Банан есть в списке!")

Полезные функции

len() — длина списка. sum() — сумма. max() и min() — максимум и минимум.

numbers = [10, 2, 11, 9] print(len(numbers)) # 4 print(sum(numbers)) # 32 print(max(numbers)) # 11 print(min(numbers)) # 2

Методы строк: split() и join()

split() разбивает строку на список. join() собирает список строк в одну строку.

words = "Python is awesome".split() # ['Python', 'is', 'awesome'] text = "-".join(['a', 'b', 'c']) # 'a-b-c'

Копирование списков

Если вы сделали list2 = list1, то изменение одного списка затронет другой. Чтобы создать независимую копию, используйте copy().

list1 = [1, 2, 3] list2 = list1.copy() list1.clear() # list1 = [], list2 = [1, 2, 3]
