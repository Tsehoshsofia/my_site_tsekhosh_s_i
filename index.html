Основы работы со списками

Список — это непрерывная динамическая коллекция элементов. Каждому элементу присваивается порядковый номер (индекс). Первый индекс равен нулю.

Изучите теорию ниже, чтобы успешно пройти следующие испытания.

1. Создание списка

Списки создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые типы данных.

my_list = [] # пустой список
numbers = [40, 20, 90, 11, 5]
cars = ['Lada Granta', 'Niva Travel', 'Lada Vesta']
mixed = [3.14, 10, 'Hello', True]

2. Индексация и изменение

Обращение к элементам идет по индексу. Списки изменяемы: вы можете заменить элемент, обратившись к нему по индексу.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta', 'УАЗ Патриот']

# Получение
print(car_models[0]) 

# Замена
car_models[1] = 'Niva Travel'
print(car_models)

# Обратный индекс (с конца)
print(car_models[-1]) # последний элемент
Lada Granta
['Lada Granta', 'Niva Travel', 'Lada Vesta', 'УАЗ Патриот']
УАЗ Патриот

3. Добавление элементов

Метод append() добавляет элемент в конец списка. Метод insert() позволяет вставить элемент на конкретную позицию.

my_list = [1, 2, 3]

my_list.append(4)
print(my_list) # [1, 2, 3, 4]

my_list.insert(1, 9) # вставить 9 на индекс 1
print(my_list) # [1, 9, 2, 3, 4]

4. Удаление элементов

remove(x) удаляет первый элемент по значению. pop(i) удаляет по индексу (или последний). Оператор del также удаляет по индексу.

variables = [10, True, 'Python', 3.14, 'Python']

variables.remove('Python') # удалит первую строку 'Python'
print(variables)

variables.pop(0) # удалит элемент с индексом 0 (число 10)
print(variables)

del variables[0] # удалит элемент с индексом 0 (True)
print(variables)
[10, True, 3.14, 'Python']
[True, 3.14, 'Python']
[3.14, 'Python']

5. Срезы списка

Срез — это подпоследовательность. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается в результат.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ']

print(cars[:3])   # с 0 по 2 индекс
print(cars[1:3])  # с 1 по 2 индекс
print(cars[1:])   # с 1 до конца
print(cars[4:2:-1]) # с шагом -1 (в обратном порядке)
['Lada', 'Niva', 'Vesta']
['Niva', 'Vesta']
['Niva', 'Vesta', 'УАЗ']
['УАЗ', 'Vesta']
