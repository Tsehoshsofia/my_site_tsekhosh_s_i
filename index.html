Ситуация 2. Индексация

Мы решили узнать, что находится в гараже. Каждый элемент имеет свой индекс, начиная с 0. Также мы можем менять машины местами или получать последнюю с помощью индекса -1.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta']
print(car_models[0]) # Lada Granta
car_models[1] = 'Niva Travel' # Замена KIA
print(car_models[-1]) # Lada Vesta

Ситуация 3. Добавление элементов

Мы купили новый автомобиль 'Aurus Senat' и хотим добавить его в конец списка. Для этого используем метод append(). А если нужно поставить машину в середину гаража — используем insert().

garage = ['Lada Granta', 'Niva Travel']
garage.append('Aurus Senat')
print(garage)

garage.insert(1, 'УАЗ Патриот')
print(garage)
['Lada Granta', 'Niva Travel', 'Aurus Senat']
['Lada Granta', 'УАЗ Патриот', 'Niva Travel', 'Aurus Senat']

Ситуация 4. Удаление элементов

Пришло время продать старую машину. Метод remove() удаляет по названию, а pop() или оператор del — по индексу.

garage = [10, 'Python', 3.14, 'Python']

garage.remove('Python') # Удалит первый 'Python'
print(garage) # [10, 3.14, 'Python']

garage.pop(0) # Удалит 10
print(garage) # [3.14, 'Python']

Ситуация 5. Срезы списка

Иногда нам нужно выбрать только часть машин. Срез работает по правилу [начало:конец:шаг]. Конечный индекс не включается в результат.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ']

print(cars[:3]) # Первые три
print(cars[1:3]) # Со второй по третью
print(cars[4:2:-1]) # В обратном порядке
['Lada', 'Niva', 'Vesta']
['Niva', 'Vesta']
['УАЗ', 'Vesta']
