Создание и индексация

Списки создаются с помощью квадратных скобок []. Каждый элемент имеет свой индекс, начиная с 0. Отрицательные индексы идут с конца: -1 — последний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0]) # Lada Granta print(car_models[-1]) # Lada Vesta

Список: ['Lada', 'KIA', 'Vesta', 'УАЗ']

Срезы списка

Срез позволяет получить подпоследовательность. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается в результат.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[:3]) # Первые три print(cars[1:3]) # Со второй по третью

Список: ['Lada', 'Niva', 'Vesta', 'УАЗ']

Добавление и удаление

Добавление: append() — в конец, insert() — на позицию.

Удаление: remove() — по значению, pop() или del — по индексу.

garage = ['Lada', 'Niva'] garage.append('Aurus') # Добавит в конец cart = ['Молоко', 'Хлеб', 'Сметана'] cart.remove('Хлеб') # Удалит 'Хлеб'

Список: ['Молоко', 'Хлеб', 'Сметана']
