Создание списка

Списки в Python создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные: числа, строки, и даже другие списки.

garage = ['Lada Granta', 'Niva Travel', 'Lada Vesta'] empty_list = list()

Индексация

Каждый элемент списка имеет свой индекс, начиная с 0. Вы можете получать элементы по индексу, менять их или использовать отрицательные индексы (например, -1 для последнего элемента).

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0]) # Lada Granta car_models[1] = 'Niva Travel' # Замена KIA print(car_models[-1]) # Lada Vesta

Добавление элементов

Чтобы добавить элемент в конец списка, используется метод append(). Если нужно вставить элемент на конкретную позицию — применяется insert().

garage = ['Lada Granta', 'Niva Travel'] garage.append('Aurus Senat') print(garage) # ['Lada Granta', 'Niva Travel', 'Aurus Senat'] garage.insert(1, 'УАЗ Патриот') print(garage) # ['Lada Granta', 'УАЗ Патриот', 'Niva Travel', 'Aurus Senat']

Удаление элементов

Метод remove() удаляет первый элемент по его значению. Метод pop() или оператор del удаляют элемент по индексу (если индекс не указан, pop() удаляет последний).

garage = [10, 'Python', 3.14, 'Python'] garage.remove('Python') # Удалит первый 'Python' print(garage) # [10, 3.14, 'Python'] garage.pop(0) # Удалит 10 print(garage) # [3.14, 'Python']

Срезы списка

Срез позволяет получить подпоследовательность элементов. Синтаксис: [начало:конец:шаг]. Конечный индекс не включается в результат.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[:3]) # Первые три print(cars[1:3]) # Со второй по третью print(cars[4:2:-1]) # В обратном порядке

Полезные функции

Для работы со списками часто используются встроенные функции: len() (длина), sum() (сумма), max() (максимум) и min() (минимум), а также методы sort() для сортировки и reverse() для переворота.

numbers = [10, 2, 11, 9] print(len(numbers)) # 4 print(sum(numbers)) # 32 print(max(numbers)) # 11 numbers.sort() print(numbers) # [2, 9, 10, 11]
