📝 Создание списка

Списки создаются с помощью квадратных скобок [] или функции list(). Внутри могут храниться любые данные.

garage = ['Lada Granta', 'Niva Travel']

🔢 Индексация

Индексы начинаются с 0. Отрицательные индексы идут с конца: -1 — последний.

car_models = ['Lada Granta', 'KIA', 'Lada Vesta'] print(car_models[0])

Список: ['Lada', 'KIA', 'Vesta', 'УАЗ']

✂️ Срезы списка

Срез: [начало:конец:шаг]. Конечный индекс не включается.

cars = ['Lada', 'Niva', 'Vesta', 'УАЗ'] print(cars[1:3])

Список: ['Lada', 'Niva', 'Vesta', 'УАЗ']

➕ Добавление: append()

Метод append(x) добавляет элемент строго в конец списка.

garage = ['Lada', 'Niva'] garage.append('Aurus')

Список: ['Lada', 'Niva']

📍 Добавление: insert()

Метод insert(index, value) вставляет элемент на конкретную позицию.

garage = ['Lada', 'Niva', 'Aurus'] garage.insert(1, 'УАЗ')

Список: ['Lada', 'Niva', 'Aurus']

🗑️ Удаление: remove()

Метод remove(x) удаляет первый элемент по значению.

cart = ['Молоко', 'Хлеб', 'Сметана'] cart.remove('Хлеб')

Список: ['Молоко', 'Хлеб', 'Сметана']

🗑️ Удаление: pop() и del

Удаляют по индексу. del просто удаляет, а pop() удаляет и возвращает значение.

cart = ['Молоко', 'Хлеб', 'Сметана'] del cart[1] # или cart.pop(1)

Список: ['Молоко', 'Хлеб', 'Сметана']

🗑️ Удаление: clear()

Метод clear() полностью очищает список.

cart = ['Молоко', 'Хлеб', 'Сметана'] cart.clear()

Список: ['Молоко', 'Хлеб', 'Сметана']

⌨️ Задача 1: Добавление товаров в конец

Давайте напишем мини-программу, которая просит ввести товар и цену. Пользователь может добавлять товары сколько угодно раз.

Обратите внимание на форматирование :g при выводе цены. Оно убирает лишние нули у целых чисел (например, 50.0 превращает в 50), но сохраняет копейки (например, 99.50 останется 99.5).

shopping_list = [] price_list = [] while True: product = input('Введите название товара: ') price = float(input('Введите стоимость товара: ')) shopping_list.append(product) price_list.append(price) answer = input('Добавить еще товар? (да/нет): ').lower() if answer != 'да': break print("\n--- ВАШ ЧЕК ---") for i in range(len(shopping_list)): print(f"{shopping_list[i]} — {price_list[i]:g} руб.") total = sum(price_list) print(f"Итого: {total:g} руб.") print("---------------")
